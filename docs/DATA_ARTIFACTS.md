# Data Artifacts Guide

This document explains how to regenerate git-ignored data artifacts required for EPIC B benchmark testing.

## Overview

The following directories contain generated artifacts that are **git-ignored**:

| Directory | Purpose | Approximate Size |
|-----------|---------|-------------------|
| `data/benchmark_inputs/` | Query sets and ground truth for retrieval evaluation | ~75KB |
| `data/screenshots/catalog/` | Screenshot metadata and OCR ground truth | ~35KB |
| `data/screenshots/raw/` | Raw generated screenshot images | ~256KB |
| `data/screenshots/processed/` | Preprocessed screenshot variants (basic/enhanced) | ~840KB |
| `output/` | Pipeline outputs (week_1, etc.) | Variable |

**Total artifact size**: ~1.2MB

## Why These Are Git-Ignored

1. **Deterministic generation**: All artifacts can be regenerated by running a single script
2. **Storage efficiency**: Binary files (images) would bloat the repository
3. **Reproducibility**: The generation script serves as the source of truth

## Quick Start

### Prerequisites

```bash
cd huecit-chatbot-rag
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### Regenerate All EPIC B Artifacts

```bash
python -m src.utils.generate_epic_b_artifacts
```

This will create:
- `data/benchmark_inputs/query_set.json` - 56 benchmark queries
- `data/benchmark_inputs/ground_truth_retrieval.json` - Retrieval mappings
- `data/screenshots/catalog/catalog.json` - Screenshot metadata
- `data/screenshots/catalog/ocr_ground_truth.json` - OCR annotations
- `data/screenshots/raw/*.png` - Raw generated screenshots
- `data/screenshots/processed/basic/*.png` - Basic preprocessed variants
- `data/screenshots/processed/enhanced/*.png` - Enhanced preprocessed variants

### Verify Generation

```bash
# Check JSON artifacts exist
ls -la data/benchmark_inputs/*.json
ls -la data/screenshots/catalog/*.json

# Check screenshots exist
ls -la data/screenshots/raw/*.png | wc -l
ls -la data/screenshots/processed/basic/*.png | wc -l
ls -la data/screenshots/processed/enhanced/*.png | wc -l

# Run validation tests
pytest tests/week1/test_schema_validator.py -v
```

## Artifact Details

### Benchmark Inputs (`data/benchmark_inputs/`)

#### `query_set.json`
Contains structured queries for benchmark testing with:
- `query_id`: Unique identifier (e.g., `q-001`)
- `query_text`: Vietnamese query text
- `query_type`: One of `procedural`, `diagnostic`, `factual`
- `difficulty`: One of `easy`, `medium`, `hard`
- `domain_id`: Domain identifier (D1-D7)
- `function_area`: Functional area (login, database, network, etc.)
- `expected_answer`: Expected response text
- `reference_doc_ids`: Linked documentation IDs
- `reference_screen_ids`: Linked screenshot IDs

#### `ground_truth_retrieval.json`
Contains retrieval ground truth mappings:
- `query_id`: Links to query_set
- `relevant_doc_ids`: Documents that should be retrieved
- `relevant_screen_ids`: Screenshots that should be retrieved

### Screenshot Catalog (`data/screenshots/catalog/`)

#### `catalog.json`
Screenshot metadata including:
- Screen ID, type, domain, function area
- Error codes and context
- OCR readiness scores
- Preprocessing pipeline status

#### `ocr_ground_truth.json`
OCR ground truth annotations:
- Screen ID and ground truth text
- Text regions with bounding boxes
- Language and annotator metadata

### Generated Screenshots

The script generates synthetic UI screenshots for each domain:
- **Raw screenshots**: Base generated images (1280x720 PNG)
- **Basic processed**: Smooth + contrast enhancement
- **Enhanced processed**: Sharpen + contrast + brightness

## Schemas

All artifacts conform to JSON schemas in `data/schemas/`:
- `query_schema.json`
- `ocr_ground_truth_schema.json`
- `screenshot_metadata_schema.json`
- `document_metadata_schema.json`
- `chunk_metadata_schema.json`
- `domain_taxonomy.json`

## CI/CD Integration

For CI/CD pipelines, add this step before running tests:

```yaml
- name: Generate EPIC B Artifacts
  run: python -m src.utils.generate_epic_b_artifacts

- name: Run Benchmark Tests
  run: pytest tests/ -v --benchmark-only
```

## Troubleshooting

### Missing Dependencies

If you see import errors:
```bash
pip install Pillow jsonschema
```

### Schema Validation Errors

The generator validates output against schemas. If validation fails:
1. Check `data/schemas/` directory exists
2. Verify `data/sample_documents/catalog.json` exists
3. Run with verbose output: `python -m src.utils.generate_epic_b_artifacts -v`

### Permission Errors

On Windows, ensure no other process has the output files open:
```bash
# Close any open file handles, then regenerate
python -m src.utils.generate_epic_b_artifacts
```
